# Seguimiento diario del levantamiento LiDAR

Tablero de solo lectura con el avance diario y el color de cada día del levantamiento.

- Los datos se capturan en una hoja de Google con las pestañas Reportes, Calendario, Valores declarados, Revuelos y Entregas. El tablero la lee directamente y se actualiza solo cada 5 minutos.
- La hoja debe estar compartida como "cualquier persona con el enlace puede ver". No cambies los nombres de las pestañas ni de las columnas: el tablero las busca por nombre.
- El color de cada día se calcula en el navegador con las reglas de la guía de supervisión, versión técnica, del 20 de noviembre de 2026.
- Para ver cómo se ve con datos, usa el botón "Ver un ejemplo" (datos ficticios).
